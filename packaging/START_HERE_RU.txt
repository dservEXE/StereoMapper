СТЕРЕОКАМЕРА — StereoMapper 0.16.0
Перенос на другой компьютер Windows x64

Это чистая сборка программы: в неё не включены прежние фотографии,
калибровки, исследования, проверочные данные и пользовательские настройки.

КАК УСТАНОВИТЬ
Обычная установка: скачайте StereoMapper-Setup.exe из
https://github.com/dservEXE/StereoMapper/releases/latest
и запустите его. Python, OpenCV и модель фото уже внутри.
Выберите папку и нажмите «Установить». Появится ярлык на рабочем столе.
Если скачали Code → Download ZIP, запустите корневой Install.cmd:
он загрузит и проверит полный установщик без установки Python вручную.

Если вы получили переносимый ZIP с готовой программой:
1. Скопируйте ZIP-архив на другой компьютер. Распакуйте его целиком
   в обычную папку: нажмите правой кнопкой по архиву → «Извлечь всё».
2. В распакованной папке StereoMapper дважды нажмите Install.cmd.
   Не запускайте файлы прямо внутри ZIP-архива.
3. Дождитесь сообщения «Готово». На рабочем столе появится ярлык
   StereoMapper. Для установки не нужны права администратора.
4. После установки флешку можно отключить. Программа установится в
   %LOCALAPPDATA%\Programs\StereoMapper

ЗАПУСК БЕЗ УСТАНОВКИ
После полной распаковки можно сразу запустить StereoMapper.exe.
Все файлы и папки рядом с ним, включая среду запуска и models, должны оставаться
на месте. Для записи исследований выбирайте папку с правом записи,
например «Документы»; не помещайте её в Program Files.
Работа напрямую с флешки возможна, но запись больших 3D-карт будет
быстрее на внутреннем SSD.

ОБНОВЛЕНИЯ
Программа проверяет GitHub при запуске и затем раз в 6 часов.
Новая версия предлагается кнопками «Обновить» и «Позже».
Есть ручная проверка и выключатель автопроверки.
Для установки обновления остановите камеры и дождитесь завершения расчётов.
Калибровка, настройки, снимки и карты сохраняются. Ошибка сети
не мешает пользоваться установленной программой.
StereoMapper-Update.exe предназначен только для уже установленной программы;
для нового ПК всегда выбирайте полный StereoMapper-Setup.exe.

ЧТО НУЖНО НА ДРУГОМ ПК
• 64-разрядная Windows. Сборка предназначена для Windows 10/11 x64.
• Отдельно устанавливать Python не нужно.
• Предусмотрите около 10 ГБ свободного места для архива, распаковки и установки,
  а также отдельный запас для создаваемых 3D-карт.
• Модель глубины по одному фото включена; интернет для её загрузки
  при первом запуске не требуется. Глубина одного фото относительная,
  она не заменяет измерения в миллиметрах двумя камерами.
• Видеокарта NVIDIA необязательна: программа также работает на CPU.
  Ускорение NVIDIA требует совместимой видеокарты и установленного
  драйвера NVIDIA. При его недоступности выберите обработку на CPU.

ПЕРВОЕ ПОДКЛЮЧЕНИЕ КАМЕРЫ
1. Подключите стереокамеру напрямую к USB компьютера, по возможности
   без удлинителя. Закройте другие приложения, использующие камеры.
2. Если Windows запрашивает доступ к камере, разрешите его настольным
   приложениям в параметрах конфиденциальности Windows.
3. В приложении проверьте, где DAR_left и DAR_right: на другом ПК
   номера устройств могут измениться. Левая и правая камеры должны
   смотреть на один и тот же предмет.
4. Для первого запуска используйте 1280×720, 30 кадров/с, AUTO.
   Если поток нестабилен, попробуйте 640×480, 30 кадров/с.
5. Перед первым измерением выполните новую калибровку в выбранном
   разрешении. Снимите 20–30 разных ракурсов плоской доски: в центре
   и у краёв изображения, с разными наклонами и на разных расстояниях.
   На каждом снимке остановите и доску, и камеру. Вся доска должна
   быть видна обоим объективам. Помощь с ракурсами доступна из приложения;
   подробности — в CALIBRATION_GUIDE.md и calibration_poses.png.
   Калибровка должна соответствовать разрешению, порядку камер,
   фокусу и их взаимному положению.
6. Если используете доску на экране, на новом мониторе заново проверьте
   размер клетки линейкой. Масштаб экрана у разных ПК отличается.

ЧИСТЫЙ ЗАПУСК И ОБНОВЛЕНИЕ
При первой установке программа создаёт новые настройки и рабочие папки.
Прежние настройки, калибровки и личные данные с другого ПК не переносятся.
В рабочей папке приложения исследования сохраняются в data и output,
настройки — в settings.json, параметры экранной доски — в screen_board.json.
Размер экранной доски нужно проверить линейкой на используемом мониторе.

Для обновления полностью закройте приложение, распакуйте новый архив
в другую папку и снова запустите Install.cmd. Установка сохраняет
существующие data, output, settings.json и screen_board.json.
Резервная копия важных измерений на отдельном диске полезна перед
любым обновлением.
